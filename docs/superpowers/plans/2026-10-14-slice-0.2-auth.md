# Slice 0.2 Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add email + password auth end to end. That means `POST /auth/register`, `POST /auth/login`, a JWT-guarded `GET /auth/me`, Flutter login and register screens, a JWT persisted in browser storage, and route guarding. It is proven by a Playwright spec that runs a register → reload → logout → login round-trip against the real backend and shows that missing, garbage or tampered JWTs are rejected.

**Architecture:** The backend hashes passwords with `bcrypt` (used directly) and issues HS256 JWTs with `pyjwt`. `get_current_user` is a FastAPI dependency built on `HTTPBearer(auto_error=False)`, so every auth failure becomes a uniform `401` with `WWW-Authenticate: Bearer`. The `users` table from slice 0.1 already has every column needed, so there is **no migration**. CORS opens the API to the Flutter web origin (`:8080`). The backend's OpenAPI schema is committed as `backend/openapi.json` and guarded by a staleness test. The Flutter client is **hand-written**: `ApiClient` plus DTOs in `client/lib/data/api/`, with a Dart test that checks the field names against `openapi.json`. The client follows the existing repository pattern (`AuthRepository` with `HttpAuthRepository` and `FakeAuthRepository`). `TokenStore` sits on `shared_preferences`, which on web means localStorage key `flutter.auth_token`. `AuthController` is a `ChangeNotifier` that drives go_router's `redirect`/`refreshListenable`.

**Tech Stack:** Python 3.13, FastAPI, bcrypt, PyJWT, email-validator, SQLAlchemy 2 + psycopg 3, pytest; Flutter 3.47 (web), go_router 18, provider, `http`, `shared_preferences`; Playwright (TypeScript); podman compose.

**Spec:** `docs/superpowers/specs/2026-10-14-web-mvp-design.md` (slice 0.2 row, "Error handling", "Testing"). Also read `docs/architecture.md` ("Auth", "Dev and test tooling") and the slice 0.1 plan `docs/superpowers/plans/2026-10-14-slice-0.1-scaffold.md`, whose conventions this plan continues.

Decisions confirmed with the user:
- **The API client is hand-written, with a drift test**, not codegen. `backend/openapi.json` is committed, and a backend test fails if it is stale. A Dart test asserts that the paths and field names the client uses exist in it.

Decisions taken here (defaults, not asked):
- **Use `bcrypt` and `pyjwt` directly**, not `passlib` or `python-jose`. passlib is unmaintained and breaks against current `bcrypt`. architecture.md gets a one-line update (Task 7).

- **Register returns a token too** (auto-login), with the same `AuthResponse` shape as login.
- **Tokens:** a single access token with a 24h TTL. There is no refresh token, no revocation, and logout is client-side only.
- **Branch:** `phase0/slice-0.2-auth`, cut from `phase0/slice-0.1-scaffold`. Per the user, this line of work **never merges into `main`**, and no PRs target `main`.

## Review Focus

1. **Over-long passwords (>72 bytes, e.g. 40× `é`)** should get a 422 on register and a plain 401 on login, never a 500 from bcrypt. Pinned in Task 1 (`test_verify_password_rejects_over_72_bytes`), Task 2 (`test_register_rejects_password_over_72_bytes`, `test_login_with_overlong_password_is_401`), and Task 5 (client validator).
2. **Email case and whitespace.** If someone registers `Ana@Example.com`, logging in with `ana@example.com` works, and re-registering `ANA@example.com` returns 409, not a second account. Pinned in Task 2 integration tests and the e2e API round-trip (Task 6).
3. **Stale or garbage token in browser storage**, e.g. after `compose down -v` wipes users. The app clears the token and shows login instead of crashing or looping. Pinned in Task 4 (`restore discards a token the backend rejects`), Task 4 (`TokenStore.read ignores non-string values`), and Task 6 (`a garbage stored token is discarded`).
4. **Backend unreachable at app start.** The app shows login within ~10s instead of a blank page, and the stored token is kept. Pinned in Task 4 (`ApiClient` timeout and `ClientException` → `ApiException(0)`; `restore keeps the token when the backend is unreachable`).
5. **Forged tokens:** expired, wrong secret, `alg=none`, missing `sub`, non-integer `sub`, a deleted user, or a non-Bearer scheme. Every one returns 401 with `WWW-Authenticate: Bearer`. Pinned in Task 1 (decode) and Task 2 (`/auth/me` unit tests), plus a tampered-signature case in e2e (Task 6).

Also in scope: **re-running e2e on persisted volumes**. Every e2e email is unique per run (`uniqueEmail()`), so a second `npm test` never hits 409.

```python
"""Password hashing (bcrypt) and access-token issue/verify (HS256 JWT)."""

from datetime import UTC, datetime, timedelta

import bcrypt
import jwt

ALGORITHM = "HS256"
# bcrypt only reads the first 72 bytes, and bcrypt>=5 raises on longer input.
MAX_PASSWORD_BYTES = 72


class InvalidTokenError(Exception):
    """The bearer token is malformed, forged, expired or missing required claims."""


def hash_password(password: str) -> str:
    return bcrypt.hashpw(password.encode(), bcrypt.gensalt()).decode()


def verify_password(password: str, password_hash: str) -> bool:
    raw = password.encode()
    if len(raw) > MAX_PASSWORD_BYTES:
        return False
    return bcrypt.checkpw(raw, password_hash.encode())


def create_access_token(
    user_id: int, *, secret: str, ttl_minutes: int, now: datetime | None = None
) -> str:
    issued = now or datetime.now(UTC)
    payload = {"sub": str(user_id), "iat": issued, "exp": issued + timedelta(minutes=ttl_minutes)}
    return jwt.encode(payload, secret, algorithm=ALGORITHM)


def decode_access_token(token: str, *, secret: str) -> int:
    try:
        payload = jwt.decode(
            token, secret, algorithms=[ALGORITHM], options={"require": ["exp", "sub"]}
        )
        return int(payload["sub"])
    except (jwt.PyJWTError, ValueError, TypeError) as exc:
        raise InvalidTokenError(str(exc)) from exc
```

def _strip(value: object) -> object:
    return value.strip() if isinstance(value, str) else value


class _EmailBody(BaseModel):
    email: EmailStr

    @field_validator("email", mode="before")
    @classmethod
    def _strip_email(cls, v: object) -> object:
        return _strip(v)

    @field_validator("email")
    @classmethod
    def _lower_email(cls, v: str) -> str:
        # The unique index is case-sensitive; store and look up one canonical form.
        return v.lower()

from fastapi import Depends, HTTPException, status
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer
from sqlalchemy.orm import Session

from app.config import Settings, get_settings
from app.core.security import InvalidTokenError, decode_access_token
from app.db import get_db
from app.models import User

# auto_error=False: we raise our own uniform 401 instead of FastAPI's default 403/401 mix.
_bearer = HTTPBearer(auto_error=False)


def _unauthorized() -> HTTPException:
    return HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail="Not authenticated",
        headers={"WWW-Authenticate": "Bearer"},
    )


def get_current_user(
    credentials: HTTPAuthorizationCredentials | None = Depends(_bearer),
    db: Session = Depends(get_db),
    settings: Settings = Depends(get_settings),
) -> User:
    if credentials is None:
        raise _unauthorized()
    try:
        user_id = decode_access_token(credentials.credentials, secret=settings.jwt_secret)
    except InvalidTokenError:
        raise _unauthorized() from None
    user = db.get(User, user_id)
    if user is None:
        raise _unauthorized()
    return user

from fastapi import APIRouter, Depends, HTTPException, status
from sqlalchemy import select
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session

from app.config import Settings, get_settings
from app.core.deps import get_current_user
from app.core.security import create_access_token, hash_password, verify_password
from app.db import get_db
from app.models import User
from app.schemas.auth import AuthResponse, LoginRequest, RegisterRequest, UserOut

router = APIRouter(prefix="/auth", tags=["auth"])

_EMAIL_TAKEN = "Email already registered"


def _issue(user: User, settings: Settings) -> AuthResponse:
    token = create_access_token(
        user.id, secret=settings.jwt_secret, ttl_minutes=settings.jwt_ttl_minutes
    )
    return AuthResponse(access_token=token, user=UserOut.model_validate(user))


@router.post("/register", status_code=status.HTTP_201_CREATED, response_model=AuthResponse)
def register(
    body: RegisterRequest,
    db: Session = Depends(get_db),
    settings: Settings = Depends(get_settings),
) -> AuthResponse:
    if db.scalar(select(User.id).where(User.email == body.email)) is not None:
        raise HTTPException(status.HTTP_409_CONFLICT, _EMAIL_TAKEN)
    user = User(
        email=body.email,
        password_hash=hash_password(body.password),
        display_name=body.display_name,
    )
    db.add(user)
    try:
        db.commit()
    except IntegrityError:  # lost a race with a concurrent register of the same email
        db.rollback()
        raise HTTPException(status.HTTP_409_CONFLICT, _EMAIL_TAKEN) from None
    db.refresh(user)
    return _issue(user, settings)


@router.post("/login", response_model=AuthResponse)
def login(
    body: LoginRequest,
    db: Session = Depends(get_db),
    settings: Settings = Depends(get_settings),
) -> AuthResponse:
    user = db.scalar(select(User).where(User.email == body.email))
    if user is None or not verify_password(body.password, user.password_hash):
        raise HTTPException(
            status.HTTP_401_UNAUTHORIZED,
            "Invalid email or password",
            headers={"WWW-Authenticate": "Bearer"},
        )
    return _issue(user, settings)


@router.get("/me", response_model=UserOut)
def me(user: User = Depends(get_current_user)) -> User:
    return user

```dart
import 'dart:async';
import 'dart:convert';

import 'package:http/http.dart' as http;

/// A failed call to the Yvoty backend. [statusCode] is the HTTP status, or 0 when
/// the backend could not be reached (network error or timeout).
class ApiException implements Exception {
  ApiException(this.statusCode, this.message);

  final int statusCode;
  final String message;

  @override
  String toString() => 'ApiException($statusCode): $message';
}

/// Thin JSON-over-HTTP client for the Yvoty backend. Paths and field names mirror
/// backend/openapi.json; test/api_contract_test.dart keeps the two in sync.
class ApiClient {
  ApiClient({
    required this.baseUrl,
    http.Client? httpClient,
    this.timeout = const Duration(seconds: 10),
  }) : _http = httpClient ?? http.Client();

  final String baseUrl;
  final Duration timeout;
  final http.Client _http;

  Future<Map<String, dynamic>> postJson(String path, Map<String, Object?> body) => _send(
        () => _http.post(
          _uri(path),
          headers: const {'Content-Type': 'application/json'},
          body: jsonEncode(body),
        ),
      );

  Future<Map<String, dynamic>> getJson(String path, {String? token}) => _send(
        () => _http.get(
          _uri(path),
          headers: {if (token != null) 'Authorization': 'Bearer $token'},
        ),
      );

  Uri _uri(String path) => Uri.parse('$baseUrl$path');

  Future<Map<String, dynamic>> _send(Future<http.Response> Function() request) async {
    final http.Response res;
    try {
      res = await request().timeout(timeout);
    } on http.ClientException catch (e) {
      throw ApiException(0, e.message);
    } on TimeoutException {
      throw ApiException(0, 'Timed out after ${timeout.inSeconds}s');
    }
    if (res.statusCode < 200 || res.statusCode >= 300) {
      throw ApiException(res.statusCode, _detail(res.body));
    }
    return jsonDecode(res.body) as Map<String, dynamic>;
  }

  static String _detail(String body) {
    try {
      final decoded = jsonDecode(body);
      if (decoded is Map && decoded['detail'] is String) return decoded['detail'] as String;
    } on FormatException {
      // Not JSON (e.g. a proxy error page); fall back to the raw body.
    }
    return body;
  }
}

    required String email,
    required String password,
    required String displayName,

    final user = UserDto(id: _nextId++, email: key, displayName: displayName.trim());

  }

  Future<AuthSession> login({required String email, required String password}) async {

      throw ApiException(401, 'Invalid email or password');
    }
    return AuthSession(accessToken: tokenFor(entry.user), user: entry.user);
  }

  @override
  Future<UserDto> me(String token) async {
    for (final entry in _byEmail.values) {
      if (tokenFor(entry.user) == token) return entry.user;
    }
    throw ApiException(401, 'Not authenticated');
  }

import 'package:shared_preferences/shared_preferences.dart';

/// Persists the access token. On web, shared_preferences keeps it in localStorage
/// as `flutter.auth_token` (JSON-encoded); e2e/support/auth.ts relies on that key.
class TokenStore {
  TokenStore(this._prefs);

  static const key = 'auth_token';

  final SharedPreferences _prefs;

  /// The stored token, or null if absent or not a string (tampered storage).
  String? read() {
    final value = _prefs.get(key);
    return value is String ? value : null;
  }

  Future<void> write(String token) => _prefs.setString(key, token);

  Future<void> clear() => _prefs.remove(key);
}

import 'package:flutter/foundation.dart';

import '../../data/api/api_client.dart';
import '../../data/api/auth_dto.dart';
import '../../data/repositories/auth_repository.dart';
import '../../data/token_store.dart';

enum AuthStatus { signedOut, signedIn }

/// Session state for the app; the router listens to it to guard routes.
class AuthController extends ChangeNotifier {
  AuthController({required AuthRepository repository, required TokenStore tokens})
      : _repository = repository,
        _tokens = tokens;

  final AuthRepository _repository;
  final TokenStore _tokens;

  AuthStatus _status = AuthStatus.signedOut;
  UserDto? _user;
  String? _token;

  AuthStatus get status => _status;
  bool get isSignedIn => _status == AuthStatus.signedIn;
  UserDto? get user => _user;
  String? get token => _token;

  /// Restores a stored session. A token the backend rejects (401) is discarded;
  /// if the backend is unreachable the user starts signed out but the token is kept.
  Future<void> restore() async {
    final token = _tokens.read();
    if (token == null) return;
    try {
      _signIn(token, await _repository.me(token));
    } on ApiException catch (e) {
      if (e.statusCode == 401) await _tokens.clear();
    }
  }

  Future<void> login({required String email, required String password}) async =>
      _adopt(await _repository.login(email: email, password: password));

  Future<void> register({
    required String email,
    required String password,
    required String displayName,
  }) async =>
      _adopt(await _repository.register(
          email: email, password: password, displayName: displayName));

  Future<void> logout() async {
    await _tokens.clear();
    _token = null;
    _user = null;
    _status = AuthStatus.signedOut;
    notifyListeners();
  }

  Future<void> _adopt(AuthSession session) async {
    await _tokens.write(session.accessToken);
    _signIn(session.accessToken, session.user);
  }

  void _signIn(String token, UserDto user) {
    _token = token;
    _user = user;
    _status = AuthStatus.signedIn;
    notifyListeners();
  }
}

import type { APIRequestContext, Page } from '@playwright/test';

import { BACKEND_URL } from './urls';

export const PASSWORD = 'correct-horse-42';

/** shared_preferences on web stores values JSON-encoded under a `flutter.` prefix. */
export const TOKEN_STORAGE_KEY = 'flutter.auth_token';

/** Unique per call: compose volumes persist between runs, so fixed emails would 409. */
export function uniqueEmail(tag: string): string {
  return `e2e-${tag}-${Date.now()}-${Math.floor(Math.random() * 1e6)}@example.com`;
}

export async function registerViaApi(
  request: APIRequestContext,
  email: string = uniqueEmail('api'),
): Promise<{ token: string; email: string }> {
  const res = await request.post(`${BACKEND_URL}/auth/register`, {
    data: { email, password: PASSWORD, display_name: 'E2E Tester' },
  });
  if (res.status() !== 201) throw new Error(`register failed: ${res.status()} ${await res.text()}`);
  return { token: (await res.json()).access_token, email };
}

/** Puts a token in browser storage before the app boots (re-applied on every navigation). */
export async function seedToken(page: Page, token: string): Promise<void> {
  await page.addInitScript(
    ([key, value]) => window.localStorage.setItem(key, JSON.stringify(value)),
    [TOKEN_STORAGE_KEY, token] as const,
  );
}

export async function storedToken(page: Page): Promise<string | null> {
  const raw = await page.evaluate((key) => window.localStorage.getItem(key), TOKEN_STORAGE_KEY);
  return raw === null ? null : (JSON.parse(raw) as string);
}
```
