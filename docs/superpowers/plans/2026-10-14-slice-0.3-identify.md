# Slice 0.3 Single-Photo Identify Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed-in user picks one photo in the Flutter web app; `POST /identify` validates it, calls Pl@ntNet (fake-plantnet in every automated test), stores the photo in MinIO, persists `identifications` / `identification_images` / `identification_results`, and the app shows the ranked results. Proven by a Playwright spec that uploads a photo, sees results, and checks the three tables.

**Architecture:** Three small backend services with one job each: `image_validation` (pure function), `plantnet_client` (sole owner of the API key and the HTTP call), `storage` (boto3 over MinIO, with a separate public endpoint for presigned URLs). A thin `routers/identify.py` orchestrates them in the order *validate → Pl@ntNet → MinIO → DB*, so a rejected or rate-limited request leaves no stored objects and no rows. The client gets an `HttpIdentifyRepository` beside the existing fake, a `PhotoPicker` abstraction (so widget tests never open a real file dialog), and a global "401 on an authenticated call → logout" hook in `ApiClient`.

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy 2 + Alembic + psycopg 3, `python-multipart`, Pillow, boto3, httpx (now a runtime dep), respx + botocore `Stubber` (tests); Flutter 3.47 web, go_router, provider, `http`, `file_picker`, `image` (dev, to build test images); Playwright; podman compose.

**Spec:** `docs/superpowers/specs/2026-10-14-web-mvp-design.md` (slice 0.3 row, "Data flow", "Error handling", "Testing"). Also read `docs/architecture.md` ("Identify request flow", "Data model"), `docs/plantnet-api.md` (section on `/v2/identify`), and the slice 0.2 plan `docs/superpowers/plans/2026-10-14-slice-0.2-auth.md`, whose conventions this plan continues.

Decisions taken here (defaults, not asked):
- **Call order is validate → Pl@ntNet → MinIO → DB** (the spec's flow lists storage first; order is not a requirement). Pl@ntNet failures (429, non-plant 404, 5xx) are the common failure, and calling it first means they leave no orphan objects. If MinIO or the DB fails *after* a successful Pl@ntNet call, one credit is spent for nothing; accepted for now. An orphaned object after a DB failure is also accepted (no cleanup job in 0.3).
- **Limits:** JPEG/PNG by magic bytes (never trust `Content-Type` or the file name), at most **10 MB**, **both sides ≥ 800 px**. Over-size is 413; every other rejection is 422. The client mirrors these checks.
- **The user's file name is never sent upstream or stored**; Pl@ntNet gets `photo.<ext>`, MinIO gets `identifications/{user_id}/{uuid}.{ext}`.
- **Presigned URLs are signed against a public endpoint** (`S3_PUBLIC_URL`, default `http://127.0.0.1:9000`), because the backend reaches MinIO as `http://minio:9000` inside compose, which a browser cannot resolve.
- **Pl@ntNet `project`** comes from a new setting `PLANTNET_PROJECT` (default `all`, per the spec).
- **`Retry-After` is exposed through CORS** (`expose_headers`), otherwise browsers hide it from the client.
- **Capture screen:** the mock viewfinder/shutter/notes/5-slot strip are replaced by a preview card, a "choose photo" button and an error line. The Notes field is removed because nothing stores notes yet (it comes back with the slice that gives it a home). The `481 ids left today` pill stays hard-coded (quota UI is a later phase). The Results banner "We detected a flower in photo 1" was hard-coded; it now renders only when the response carries a `predicted_organ`.

## Review Focus

1. **Rejected input must cost nothing.** A GIF, a corrupt/truncated PNG, a 799×800 image, an empty file or a >10 MB body returns 422/413 *before* any Pl@ntNet call, MinIO write or DB row (a rejected request still burns a credit on the free plan). Pinned in Task 2 (validator unit tests), Task 6 (`test_rejected_images_touch_nothing`) and Task 10 (e2e rows-unchanged assertions).
2. **Pl@ntNet failures leave no trace.** 429 (with `Retry-After` passed through), 404 "no plant", 5xx, timeouts and unparseable bodies each map to 429 / 422 / 502 with no stored object and no rows, and the API key never leaks into any message. Pinned in Task 3 (client tests incl. `test_errors_never_contain_the_api_key`) and Task 6.
3. **MinIO or DB failing mid-request** returns a clean 502/500 rather than a half-written identification (no `identifications` row without its images and results). Pinned in Task 4 (`StorageError`), Task 5 (single transaction, rollback) and Task 6 (`test_storage_failure_is_502_and_commits_nothing`).
4. **Presigned URL must work from the browser**, not just from inside compose (public host, not `minio:9000`), and must expire. Pinned in Task 4 (`test_presign_uses_public_endpoint`), Task 5 (real MinIO round-trip) and Task 10 (e2e GETs the returned URL).
5. **Session dies mid-flow** (token expired or user deleted after the app started): `/identify` returns 401, the app clears the token and lands on login instead of showing a generic error. Pinned in Task 7 (`ApiClient` hook) and Task 10 (e2e deletes the user via SQL, then identifies).

Also in scope: **persisted volumes**. Bucket creation is lazy and idempotent, so a fresh `compose down -v` and a reused MinIO volume both work; e2e emails stay unique per run.

```python
import io

from PIL import Image


def _encode(fmt: str, width: int, height: int) -> bytes:
    buf = io.BytesIO()
    Image.new("RGB", (width, height), (40, 120, 60)).save(buf, fmt)
    return buf.getvalue()


def png_bytes(width: int = 800, height: int = 800) -> bytes:
    return _encode("PNG", width, height)


def jpeg_bytes(width: int = 800, height: int = 800) -> bytes:
    return _encode("JPEG", width, height)
```

```python
"""Server-side photo checks, run before any Pl@ntNet call (a rejected call still costs a credit).

Mirrors the client's `photoProblem()` in client/lib/data/photo_validation.dart.
"""

import io
from dataclasses import dataclass

from PIL import Image, UnidentifiedImageError

MAX_IMAGE_BYTES = 10 * 1024 * 1024
MIN_SIDE_PX = 800

_PNG_MAGIC = b"\x89PNG\r\n\x1a\n"
_JPEG_MAGIC = b"\xff\xd8\xff"


class ImageRejected(Exception):
    def __init__(self, message: str, status_code: int = 422):
        super().__init__(message)
        self.message = message
        self.status_code = status_code


@dataclass(frozen=True)
class ValidatedImage:
    ext: str
    content_type: str
    width: int
    height: int


def validate_image(data: bytes) -> ValidatedImage:
    if len(data) > MAX_IMAGE_BYTES:
        raise ImageRejected("Photo is larger than 10 MB", status_code=413)
    if data.startswith(_PNG_MAGIC):
        ext, content_type = "png", "image/png"
    elif data.startswith(_JPEG_MAGIC):
        ext, content_type = "jpg", "image/jpeg"
    else:
        raise ImageRejected("Only JPEG and PNG photos are supported")
    try:
        with Image.open(io.BytesIO(data)) as img:
            width, height = img.size
            img.load()  # full decode: catches truncated files that still have a valid header
    except (UnidentifiedImageError, OSError, SyntaxError, ValueError, Image.DecompressionBombError):
        raise ImageRejected("That file could not be read as an image") from None
    if width < MIN_SIDE_PX or height < MIN_SIDE_PX:
        raise ImageRejected(
            f"Photo must be at least {MIN_SIDE_PX}x{MIN_SIDE_PX} pixels (this one is {width}x{height})"
        )
    return ValidatedImage(ext=ext, content_type=content_type, width=width, height=height)
```

```python
"""Sole owner of the Pl@ntNet API key and the HTTP call (docs/plantnet-api.md).

The key travels in the query string, so exception messages here are fixed strings and the
original httpx error (whose text can include the URL) is suppressed with `from None`.
"""

import httpx
from fastapi import Depends
from pydantic import BaseModel, ValidationError

from app.config import Settings, get_settings


class PlantnetError(Exception):
    pass


class PlantnetRateLimited(PlantnetError):
    def __init__(self, retry_after: str | None):
        super().__init__("Pl@ntNet rate limit reached")
        self.retry_after = retry_after


class PlantnetNoPlant(PlantnetError):
    """Pl@ntNet answered 404 'Species not found': the photo does not look like a plant."""


class PlantnetUnavailable(PlantnetError):
    pass


class NamedTaxon(BaseModel):
    scientificNameWithoutAuthor: str


class ExternalId(BaseModel):
    id: int | str


class Species(BaseModel):
    scientificName: str
    scientificNameWithoutAuthor: str
    genus: NamedTaxon | None = None
    family: NamedTaxon | None = None
    commonNames: list[str] = []


class Candidate(BaseModel):
    score: float
    species: Species
    gbif: ExternalId | None = None
    powo: ExternalId | None = None


class PredictedOrgan(BaseModel):
    organ: str
    score: float


class PlantnetResponse(BaseModel):
    bestMatch: str | None = None
    results: list[Candidate]
    predictedOrgans: list[PredictedOrgan] = []
    version: str | None = None
    remainingIdentificationRequests: int | None = None


class PlantnetClient:
    def __init__(self, base_url: str, api_key: str, timeout: float = 30.0):
        self._base_url = base_url.rstrip("/")
        self._api_key = api_key
        self._timeout = timeout

    def identify(
        self,
        *,
        project: str,
        filename: str,
        content: bytes,
        content_type: str,
        organ: str = "auto",
    ) -> PlantnetResponse:
        try:
            res = httpx.post(
                f"{self._base_url}/v2/identify/{project}",
                params={"api-key": self._api_key},
                files={"images": (filename, content, content_type)},
                data={"organs": organ},
                timeout=self._timeout,
            )
        except httpx.HTTPError:
            raise PlantnetUnavailable("Could not reach Pl@ntNet") from None
        if res.status_code == 429:
            raise PlantnetRateLimited(res.headers.get("Retry-After"))
        if res.status_code == 404:
            raise PlantnetNoPlant("No plant detected")
        if res.status_code != 200:
            raise PlantnetUnavailable(f"Pl@ntNet answered HTTP {res.status_code}")
        try:
            return PlantnetResponse.model_validate(res.json())
        except (ValueError, ValidationError):
            raise PlantnetUnavailable("Pl@ntNet sent an unexpected response") from None


def get_plantnet_client(settings: Settings = Depends(get_settings)) -> PlantnetClient:
    return PlantnetClient(settings.plantnet_base_url, settings.plantnet_api_key)
```

```python
"""S3-protocol adapter over MinIO. The bucket is created lazily on first upload (idempotent)."""

from functools import lru_cache

import boto3
from botocore.client import Config
from botocore.exceptions import BotoCoreError, ClientError
from fastapi import Depends

from app.config import Settings, get_settings


class StorageError(Exception):
    pass


class Storage:
    def __init__(
        self, *, endpoint_url: str, public_url: str, access_key: str, secret_key: str, bucket: str
    ):
        common = {
            "aws_access_key_id": access_key,
            "aws_secret_access_key": secret_key,
            "region_name": "us-east-1",
            "config": Config(
                signature_version="s3v4",
                s3={"addressing_style": "path"},
                connect_timeout=5,
                read_timeout=15,
                retries={"max_attempts": 2},
            ),
        }
        self._client = boto3.client("s3", endpoint_url=endpoint_url, **common)
        # Presigning is a local computation, so a second client bound to the public host is free.
        self._signer = boto3.client("s3", endpoint_url=public_url, **common)
        self._bucket = bucket
        self._bucket_ready = False

    def _ensure_bucket(self) -> None:
        if self._bucket_ready:
            return
        try:
            self._client.head_bucket(Bucket=self._bucket)
        except ClientError as e:
            if e.response.get("Error", {}).get("Code") not in ("404", "NoSuchBucket", "NotFound"):
                raise
            self._client.create_bucket(Bucket=self._bucket)
        self._bucket_ready = True

    def put(self, key: str, data: bytes, content_type: str) -> None:
        try:
            self._ensure_bucket()
            self._client.put_object(
                Bucket=self._bucket, Key=key, Body=data, ContentType=content_type
            )
        except (BotoCoreError, ClientError):
            raise StorageError("Could not store the photo") from None

    def presign(self, key: str, expires: int = 3600) -> str:
        return self._signer.generate_presigned_url(
            "get_object", Params={"Bucket": self._bucket, "Key": key}, ExpiresIn=expires
        )


@lru_cache
def _storage_for(endpoint_url: str, public_url: str, access_key: str, secret_key: str, bucket: str):
    return Storage(
        endpoint_url=endpoint_url,
        public_url=public_url,
        access_key=access_key,
        secret_key=secret_key,
        bucket=bucket,
    )


def get_storage(settings: Settings = Depends(get_settings)) -> Storage:
    return _storage_for(
        settings.s3_endpoint_url,
        settings.s3_public_url,
        settings.s3_access_key,
        settings.s3_secret_key,
        settings.s3_bucket,
    )
```

```python
        self.objects[key] = (data, content_type)

    def presign(self, key: str, expires: int = 3600) -> str:
        return f"http://files.test/{key}?sig=1"


class RecordingSession:
    """Stand-in for a SQLAlchemy Session that records what the code under test does."""

    def __init__(self, fail_on_commit: Exception | None = None):
        self.fail_on_commit = fail_on_commit
        self.added: list = []
        self.commits = 0
        self.rollbacks = 0

    def add(self, obj) -> None:
        self.added.append(obj)

    def commit(self) -> None:
        if self.fail_on_commit is not None:
            raise self.fail_on_commit
        self.commits += 1
        for obj in self.added:
            if isinstance(obj, Identification) and obj.id is None:
                obj.id = 7

    def rollback(self) -> None:
        self.rollbacks += 1

    def get(self, _model, _id):
        return None
```

```python
from sqlalchemy.orm import Session

from app.models import Identification, IdentificationImage, IdentificationResult
from app.services.plantnet_client import PlantnetResponse


def persist_identification(
    db: Session,
    *,
    user_id: int,
    project: str,
    response: PlantnetResponse,
    image_key: str,
    organ: str,
) -> Identification:
    """Writes the identification, its image and every ranked candidate in one transaction."""
    predicted = response.predictedOrgans[0] if response.predictedOrgans else None
    ident = Identification(
        user_id=user_id,
        project=project,
        best_match=response.bestMatch,
        remaining_requests_at_call=response.remainingIdentificationRequests,
        plantnet_version=response.version,
    )
    ident.images.append(
        IdentificationImage(
            storage_key=image_key,
            organ=organ,
            predicted_organ=predicted.organ if predicted else None,
            predicted_organ_score=predicted.score if predicted else None,
            sort_order=0,
        )
    )
    for rank, candidate in enumerate(response.results, start=1):
        species = candidate.species
        ident.results.append(
            IdentificationResult(
                rank=rank,
                score=candidate.score,
                scientific_name=species.scientificName,
                scientific_name_without_author=species.scientificNameWithoutAuthor,
                genus=species.genus.scientificNameWithoutAuthor if species.genus else None,
                family=species.family.scientificNameWithoutAuthor if species.family else None,
                common_names=list(species.commonNames),
                gbif_id=str(candidate.gbif.id) if candidate.gbif else None,
                powo_id=str(candidate.powo.id) if candidate.powo else None,
            )
        )
    db.add(ident)
    try:
        db.commit()
    except Exception:
        db.rollback()
        raise
    return ident
```

```python
from fastapi import APIRouter, Depends, HTTPException, UploadFile, status

from app.config import Settings, get_settings
from app.core.deps import get_current_user
from app.db import get_db
from app.models import User

from app.services.identifications import persist_identification
from app.services.image_validation import MAX_IMAGE_BYTES, ImageRejected, validate_image
from app.services.plantnet_client import (
    PlantnetClient,
    PlantnetError,
    PlantnetNoPlant,
    PlantnetRateLimited,
    get_plantnet_client,
)
from app.services.storage import Storage, StorageError, get_storage

router = APIRouter(tags=["identify"])

# Slice 0.3 sends one photo with no organ hint; 0.4 adds real organ tags.
_ORGAN = "auto"


@router.post("/identify", response_model=IdentifyResponse)
def identify(
    image: UploadFile,
    user: User = Depends(get_current_user),
    db: Session = Depends(get_db),
    settings: Settings = Depends(get_settings),
    plantnet: PlantnetClient = Depends(get_plantnet_client),
    storage: Storage = Depends(get_storage),
) -> IdentifyResponse:
    # Read one byte past the cap so an oversize body is detected without buffering all of it.
    data = image.file.read(MAX_IMAGE_BYTES + 1)
    try:
        photo = validate_image(data)
    except ImageRejected as e:
        raise HTTPException(e.status_code, e.message) from None

    # Pl@ntNet first: its failures (429, non-plant, outage) are common and must not leave
    # orphaned objects in storage.
    try:
        response = plantnet.identify(
            project=settings.plantnet_project,
            filename=f"photo.{photo.ext}",
            content=data,
            content_type=photo.content_type,
            organ=_ORGAN,
        )
    except PlantnetRateLimited as e:
        headers = {"Retry-After": e.retry_after} if e.retry_after else None
        raise HTTPException(
            status.HTTP_429_TOO_MANY_REQUESTS, "Daily identification limit reached", headers=headers
        ) from None
    except PlantnetNoPlant:
        raise HTTPException(
            status.HTTP_422_UNPROCESSABLE_ENTITY, "No plant detected in this photo"
        ) from None
    except PlantnetError:
        raise HTTPException(
            status.HTTP_502_BAD_GATEWAY, "Identification service unavailable"
        ) from None

    key = f"identifications/{user.id}/{uuid.uuid4().hex}.{photo.ext}"
    try:
        storage.put(key, data, photo.content_type)
    except StorageError:
        raise HTTPException(status.HTTP_502_BAD_GATEWAY, "Photo storage unavailable") from None

    ident = persist_identification(
        db,
        user_id=user.id,
        project=settings.plantnet_project,
        response=response,
        image_key=key,
        organ=_ORGAN,
    )
    stored = ident.images[0]
    return IdentifyResponse(
        identification_id=ident.id,
        project=ident.project,
        best_match=ident.best_match,
        remaining_requests=ident.remaining_requests_at_call,
        image=IdentifyImageOut(
            url=storage.presign(stored.storage_key),
            predicted_organ=stored.predicted_organ,
            predicted_organ_score=stored.predicted_organ_score,
        ),
        results=[IdentifyResultOut.model_validate(r, from_attributes=True) for r in ident.results],
    )
```

```dart
import 'dart:typed_data';
import 'dart:ui' as ui;

/// Mirrors backend/app/services/image_validation.py so a photo that would be rejected
/// never leaves the browser (a rejected Pl@ntNet call still costs a credit).
const int kMaxPhotoBytes = 10 * 1024 * 1024;
const int kMinPhotoSide = 800;

const _pngMagic = [0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A];
const _jpegMagic = [0xFF, 0xD8, 0xFF];

bool _startsWith(Uint8List bytes, List<int> prefix) {
  if (bytes.length < prefix.length) return false;
  for (var i = 0; i < prefix.length; i++) {
    if (bytes[i] != prefix[i]) return false;
  }
  return true;
}

/// A user-facing reason this photo cannot be identified, or null if it can be sent.
Future<String?> photoProblem(Uint8List bytes) async {
  if (bytes.length > kMaxPhotoBytes) return 'Photo is larger than 10 MB.';
  if (!_startsWith(bytes, _pngMagic) && !_startsWith(bytes, _jpegMagic)) {
    return 'Only JPEG and PNG photos are supported.';
  }
  int width, height;
  try {
    final codec = await ui.instantiateImageCodec(bytes);
    final frame = await codec.getNextFrame();
    width = frame.image.width;
    height = frame.image.height;
    frame.image.dispose();
    codec.dispose();
  } catch (_) {
    return 'That file could not be read as an image.';
  }
  if (width < kMinPhotoSide || height < kMinPhotoSide) {
    return 'Photo must be at least $kMinPhotoSide×$kMinPhotoSide pixels (this one is $width×$height).';
  }
  return null;
}
```

```ts
import { deflateSync, crc32 } from 'node:zlib';

function chunk(type: string, data: Buffer): Buffer {
  const len = Buffer.alloc(4);
  len.writeUInt32BE(data.length);
  const body = Buffer.concat([Buffer.from(type, 'ascii'), data]);
  const crc = Buffer.alloc(4);
  crc.writeUInt32BE(crc32(body));
  return Buffer.concat([len, body, crc]);
}

/** A valid solid-green RGB PNG of the given size (a few KB even at 1024x1024). */
export function makePng(width: number, height: number): Buffer {
  const ihdr = Buffer.alloc(13);
  ihdr.writeUInt32BE(width, 0);
  ihdr.writeUInt32BE(height, 4);
  ihdr[8] = 8; // bit depth
  ihdr[9] = 2; // colour type: truecolour
  const row = Buffer.alloc(1 + width * 3);
  for (let x = 0; x < width; x++) row.set([40, 120, 60], 1 + x * 3);
  const raw = Buffer.concat(Array.from({ length: height }, () => row));
  return Buffer.concat([
    Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]),
    chunk('IHDR', ihdr),
    chunk('IDAT', deflateSync(raw)),
    chunk('IEND', Buffer.alloc(0)),
  ]);
}
```

```ts
import { execFileSync } from 'node:child_process';
import path from 'node:path';

const ROOT = path.resolve(__dirname, '..', '..');

/** Runs a query in the compose Postgres and returns its trimmed stdout (-At: bare values). */
export function sql(query: string): string {
  return execFileSync(
    'podman',
    ['compose', 'exec', '-T', 'postgres', 'psql', '-U', 'yvoty', '-d', 'yvoty', '-At', '-c', query],
    { cwd: ROOT, encoding: 'utf8' },
  ).trim();
}

/** Rows of an identification table owned by the user with this e2e email. */
export function countRows(
  table: 'identifications' | 'identification_images' | 'identification_results',
  email: string,
): number {
  const owner =
    table === 'identifications'
      ? 'i.id = t.id'
      : 'i.id = t.identification_id';
  return Number(
    sql(
      `SELECT count(*) FROM ${table} t JOIN identifications i ON ${owner} ` +
        `JOIN users u ON u.id = i.user_id WHERE u.email = '${email}'`,
    ),
  );
}
```
